# jolt-lang boot chain (vendored)

This tree is the compile-time `##include` closure of
`host/gambit/boot-probe.scm` — the jolt kernel boot with a live compiler that
`stage.sh serve` splices into the freestanding unikernel. It is vendored here so
the example builds from this repository alone, with no external `jolt-lang`
checkout.

Source: `racklr-dev/jolt-lang` @ `e15366991d22de0ccca5e051eb16b73e89da6d49`.

- `host/gambit/boot-probe.scm` — entry point; `##include`s `boot-full.ss` and
  prints `BOOT-OK`.
- `host/gambit/boot-full.ss` — GENERATED by `host/gambit/gen-boot.ss` (profile
  `full`); do not edit. Regenerate from jolt-lang and re-vendor, or the closure
  drifts.
- `host/gambit/prelude-shims.ss` — carries the fixnum fix: `most-negative-fixnum`
  is computed by doubling `-1` until it leaves fixnum range, NOT via
  `(expt 2 (- (##fixnum-width) 1))`, which the C compiler emits as a CALL to a
  runtime *variable* and dies with "Operator is not a PROCEDURE" at boot.

Only the 60 files the boot actually splices are vendored (7.1 MB); the rest of
`host/` (dev-time gate scripts, Chez-only files, generated `.c`) is not needed
here.
